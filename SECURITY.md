# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities through a [GitHub Security
Advisory](https://github.com/Xenotech-Studio/flops-agent/security/advisories/new).
Do not include exploit details in a public issue. Include affected versions,
reproduction steps, impact, and any suggested mitigation where possible.

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | Yes |
| Earlier versions | No |

Support applies only to the current supported release line. The project makes no
out-of-window support commitment for earlier versions.
